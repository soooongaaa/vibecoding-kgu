# 과일 사격 (fruit-shooting)

담당: joyuni (feature/game-joyuni-a) · 12개 미니게임 중 하나

## 개요

마우스(칼 커서)로 조준·클릭해서 하늘로 날아오르는 과일을 베어(맞춰) 터뜨리는 아케이드 게임.
`src/games/brick-breaker/`와 동일한 패턴(단일 클라이언트 컴포넌트 + CSS 모듈, 자체 상태만 사용,
백엔드/DB 없음)을 따른다. 통과 여부만 화면에 표시하고, 점수 저장·랭킹은 이 게임의 범위가 아니다
(공통 스캐폴드가 준비되면 그때 연동).

원래 "클레이 사격"(clay-shooting)으로 시작했으나, 과일을 베어 터뜨리는 컨셉으로 리스킨하면서
폴더/라우트/컴포넌트 이름도 `fruit-shooting`/`FruitShooting`으로 전부 변경했다.

## 화면 진입

- 라우트: `/games/fruit-shooting`
- 진입 파일: `src/app/games/fruit-shooting/page.tsx` (brick-breaker와 동일하게 `<FruitShooting />`만 렌더링하는 얇은 래퍼)
- 로그인 여부 체크는 하지 않는다 (brick-breaker도 하지 않음 — 로그인·인증은 다른 팀원 담당 영역).

## 게임 규칙

- 캔버스 900×600 (CSS로 반응형 스케일).
- 제한시간 60초.
- 약 3초 간격으로 과일 2개가 화면 하단 좌/우에서 동시에 발사되어 포물선(중력) 궤적으로 날아간다.
  첫 페어는 시작 즉시(0초) 등장하고, 마지막 스폰은 57초에 일어나 60초 종료 시점에 허공에 뜬 채
  결과 화면에 가려지는 과일이 없도록 한다 (60초 동안 총 20회 스폰 × 2개 = 40개).
- 과일 종류는 사과🍎/오렌지🍊/포도🍇/딸기🍓/바나나🍌 중 스폰마다 무작위로 하나씩 선택된다.
- 클릭한 지점과 겹치는(원형 히트박스) 활성 과일이 있으면 명중: 해당 과일 색의 즙 파티클이 방사형으로
  터지는 버스트 이펙트 후 제거, 명중 수 +1.
- 화면 밖으로 나간 과일은 자동 소멸(미스, 감점 없음).
- 물리는 실제 경과 시간(ms) 기준으로 정규화되어 모니터 주사율(60Hz/144Hz 등)과 무관하게 동일한
  속도로 진행된다. 탭 전환 등으로 프레임 간격이 크게 벌어지면 프레임 delta를 최대 100ms로 clamp해
  시간 증발이나 과일 뭉침 스폰을 막는다.
- **명중 수 ≥ 20 → 통과(Clear)**, 미만 → **실패(Fail)**.
- 화면에는 남은 시간(정수 초 단위로만 갱신)과 현재 명중 수를 실시간 표시.
- 종료 시 결과 오버레이: 통과/실패 여부 + 최종 명중 수 + "다시 하기" 버튼. 종료 순간 남아있던
  과일과 파티클은 모두 제거되어 오버레이 뒤에 잔상이 남지 않는다.
- 마우스 커서는 칼 모양 커스텀 커서로 표시된다 (`FruitShooting.module.css`의 `cursor` 속성,
  인라인 SVG data URI, 외부 이미지 파일 없음). 클릭 판정 좌표는 실제 커서 위치를 그대로 쓰므로
  커서 아이콘의 정확한 hotspot 정렬은 순수 시각적 요소이며 판정에 영향을 주지 않는다.

## 상태 머신

```
"ready" -> "playing" -> "cleared" | "failed" -> (다시 하기) -> "playing"
```

## 파일 구성

```
src/games/fruit-shooting/
├── SPEC.md                        # 이 문서
├── PLAN.md                        # 구현 계획 + 리뷰 이후 수정 내역(Amendment)
├── FruitShooting.tsx               # "use client" 게임 본체
├── FruitShooting.module.css        # 스타일 + 칼 커서
└── engine.ts                       # 순수 함수: 과일 스폰/포물선 위치 계산/원형 히트테스트
src/app/games/fruit-shooting/
└── page.tsx                        # 얇은 라우트 래퍼
```

## 범위 밖 (Out of scope)

- Supabase 테이블/API 라우트 — 만들지 않는다. 공통 점수/결과 전달 방식은 `feature/game-common`이
  생기면 그때 연결한다.
- 로그인 체크, 전역 네비게이션/허브 화면 연동 — 다른 팀원 담당.
- 콤보/배율, 탄약 제한 — 요청받지 않음.
- 자동화 테스트 — 레포에 테스트 프레임워크가 없어 추가하지 않는다. `npm run lint` +
  `npm run build` + 로컬 플레이 확인으로 검증한다.

## 완료 기준

- `/games/fruit-shooting` 접속 가능.
- 시작 → 플레이(60초, 과일 페어 스폰) → 종료 → 결과(통과/실패) → 다시 하기 흐름이 동작.
- 모바일 화면에서도 탭으로 조작 가능 (실제 터치 명중 반경이 충분한지는 추가 플레이테스트 필요 —
  현재는 마우스와 동일한 반경을 사용).
- 브라우저 콘솔에 오류 없음.
- `npm run lint`, `npm run build` 통과.
- `src/games/fruit-shooting/`, `src/app/games/fruit-shooting/` 밖의 파일은 수정하지 않음.
