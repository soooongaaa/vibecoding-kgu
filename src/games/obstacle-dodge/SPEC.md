# 쓰레기 피하기 드라이브 (obstacle-dodge)

담당: joyuni (feature/game-joyuni-b) · 12개 미니게임 중 하나

## 개요

도로를 위에서 내려다보는 탑뷰 드라이빙 게임. 차선을 오가며 위에서 떨어지는 쓰레기(장애물)를
피해 정해진 시간을 버티면 통과한다. `src/games/brick-breaker/`, `src/games/fruit-shooting/`와
동일한 패턴(단일 클라이언트 컴포넌트 + CSS 모듈, 자체 상태만 사용, 백엔드/DB 없음)을 따른다.

이 게임은 원래 사용자 요청으로 순수 HTML/CSS/JS 단일 파일(외부 라이브러리·이미지 없이 Canvas
도형 + 이모지만 사용)로 먼저 완성되어 실제로 플레이·검증(Artifact로 배포해 직접 플레이 확인)까지
마친 상태다. 이번 작업은 그 게임 로직·디자인을 그대로 유지하면서 팀 컨벤션에 맞게
Next.js(React) 컴포넌트 구조로 포팅하는 것이다 — 게임 규칙이나 밸런스를 새로 설계하지 않는다.

## 화면 진입

- 라우트: `/games/obstacle-dodge`
- 진입 파일: `src/app/games/obstacle-dodge/page.tsx` (brick-breaker/fruit-shooting과 동일하게
  `<ObstacleDodge />`만 렌더링하는 얇은 래퍼)
- 로그인 여부 체크는 하지 않는다 (다른 게임들도 하지 않음 — 로그인·인증은 다른 팀원 담당).
- 12지신 동물 허브(`src/lib/game/zoo-games.ts`, `src/app/games/[animal]/`)에 연결하는 것은
  이번 작업 범위가 아니다 — 어떤 동물 칸이 joyuni에게 배정됐는지 알 수 없고, 공용 파일이라
  임의로 수정하지 않는다 (fruit-shooting도 동일하게 허브 연동을 범위 밖으로 뒀다).

## 게임 규칙 (원본 프로토타입과 동일, 변경 없음)

- 캔버스 420×640 (CSS로 반응형 스케일).
- 도로에 4차선, 좌우로 풀밭 가장자리. 차선 사이 흰 점선이 아래로 흐르는 스크롤 애니메이션으로
  주행감을 표현한다 (실제로는 차가 고정, 점선이 흐름).
- 제한시간 30초 동안 생존하면 통과. 목숨은 1개 — 쓰레기와 충돌하면 즉시 실패, 재도전 가능.
- 플레이어 차량은 화면 하단 고정 높이에서 차선 간 좌우로만 이동(부드럽게 목표 차선 중심으로
  미끄러지듯 슬라이드).
- 쓰레기(장애물)는 트래시백/상자/타이어 3종류가 무작위 차선·무작위 종류로 화면 위에서 아래로
  낙하한다. 경과 시간에 따라 낙하 속도와 등장 빈도가 선형으로 증가해 난이도가 올라간다.
- 충돌 판정은 차량과 쓰레기의 사각형(중심 좌표 기준) 겹침만 보는 단순 AABB 방식.
- 화면 상단에 남은 시간 텍스트 + 진행률 바(시간이 지날수록 줄어듦) 표시.
- 결과 화면: 통과 시 초록 톤 "PASS" + 생존 시간, 실패 시 빨강 톤 "FAIL" + 충돌까지 걸린 시간.
  "다시하기" 버튼으로 즉시 재시작(시작 화면으로 돌아가지 않음).

## 조작 방법

- 키보드 ← → 방향키로 차선 이동.
- 모바일: 캔버스 좌/우 절반 탭, 또는 좌우 스와이프(임계값 이상 이동 시 스와이프로 인식,
  그보다 작으면 탭 위치로 판단).

## 물리/타이밍 정확성

fruit-shooting 최종 리뷰에서 발견된 문제(프레임 기반 물리가 모니터 주사율에 따라 난이도가
달라지는 버그)를 이 게임에서는 처음부터 피한다 — 장애물 이동·차선 슬라이드·스크롤 오프셋
전부 `requestAnimationFrame`이 넘겨주는 실제 경과 시간(ms)을 기준으로 계산하고, 한 프레임의
delta는 최대 50ms로 clamp해 탭 전환 등으로 인한 시간 폭주도 방지한다.

## 상태 머신

```
"ready" -> "playing" -> "cleared"(PASS) | "failed"(FAIL) -> (다시하기) -> "playing"
```


## 범위 밖 (Out of scope)

- Supabase 테이블/API 라우트, 로그인 체크, 12지신 허브 연동, 자동화 테스트 — 다른 게임들과
  동일하게 범위 밖. `npm run lint` + `npm run build` + 로컬 실행 확인으로 검증한다.

## 완료 기준

- `/games/obstacle-dodge` 접속 가능.
- 시작 → 플레이(30초, 난이도 증가) → 종료 → 결과(PASS/FAIL) → 다시하기 흐름이 동작.
- 키보드와 모바일 터치(탭/스와이프) 양쪽 조작이 모두 동작.
- 브라우저 콘솔에 오류 없음.
- `npm run lint`, `npm run build` 통과.
- `src/games/obstacle-dodge/`, `src/app/games/obstacle-dodge/` 밖의 파일은 수정하지 않음.
